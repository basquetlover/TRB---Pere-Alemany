# TRB – Dron amb Cap Mòbil LED

## Descripción

Este proyecto presenta el diseño y estudio de un dron con cabeza móvil de iluminación LED para eventos. El objetivo es reemplazar los sistemas de iluminación fijos tradicionales por una solución más flexible y dinámica. Se ha utilizado el DJI FlyCart 30, un dron de 65 kg diseñado para transporte de mercancías, modificado para llevar una batería y una cabeza móvil de iluminación. Esta solución permite explorar diferentes cabezas móviles de iluminación escénica (Wash, Beam y Spot) para crear diversos efectos.

## Tecnologías

* **HTML5**: Estructura semántica y accesible del contenido.
* **CSS3**: Estilos personalizados para una presentación atractiva y responsive.
* **JavaScript**: Interactividad básica para mejorar la experiencia de usuario.

## Características

* Diseño responsive para visualización óptima en móviles y escritorios.
* Galería de imágenes del modelo 3D del dron y los cabezales de iluminación.
* Enlaces a recursos adicionales y modelos 3D para una comprensión más profunda del proyecto.

## Instalación

1. Clona este repositorio:

```bash
git clone https://github.com/usuari/trb-pere-alemany.git
```

2. Accede a la carpeta del proyecto:

```bash
cd trb-pere-alemany
```

3. Abre el archivo `index.html` en tu navegador preferido para ver la página.
